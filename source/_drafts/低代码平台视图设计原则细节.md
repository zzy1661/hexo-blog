原则：
易用，通用，统一

采用统一的UI组件库，二开或独立封装的组件也应尽量符合该组件库的ui分格。
涉及到具体的选型，如果是react生态，推荐是Ant Design 或 Material Design。

1. 记住用户习惯
1.1 常用查询可保存为模板
1.2 常用导出字段可保存为模板
1.3 记忆列字段展示隐藏排序行高设置等
1.4 记忆导入向导字段映射

2. 查询区
日期范围选择器提供快捷操作：最近一周，上个月等。

提供查询结果页签。

2. table表格尽量保持每行固定高度
2.1 保持固定高度，内容显示不下应用eslipse
2.2 单元格默认以title形式提供悬浮提示
2.3 富文本/文件/图片字段，点击弹窗展示
2.4 提供全屏模式
2.5 提供滚动分页和普通分页两种模式
2.6 支持行内编辑
2.7 支持用户自己调整列宽行高展示字段及其排序

3. 表单
包括新增/编辑表单与只读的详情类表单
3.1 所有可输入项提供placeholder
3.2 表单项可进行分组
3.3 详情表单项名称与表单值应有明显的区分，比如通过颜色、背景色、下划线等手段
3.4 下拉框支持搜索

其他
3. 字段悬浮提示用tooltip，其他用popover
校验错误可自动滚动至错误项
所有带校验（必填除外）的字段，默认具备悬浮提示，内容为校验规则名称；必填字段以*表示。

抽屉按钮位置在上，弹窗按钮位置在下

4. 数据
空值格式化，默认null,空字符串展示为"--"
金额类型默认以千分位分隔符隔开
